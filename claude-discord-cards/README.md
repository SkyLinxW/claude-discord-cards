# Claude Discord Cards

Cards animados do status do Claude Code no Discord (Rich Presence).
O daemon usa as URLs raw destes arquivos como `large_image`: só imagem
externa anima no Discord; o Art Assets do Developer Portal mostra parado.

| Card | Estado |
|---|---|
| `card-working.gif` | escrevendo código / rodando comando |
| `card-thinking.gif` | pensando / lendo / buscando |
| `card-waiting.png` | aguardando aprovação |
| `card-idle.png` | parado |
